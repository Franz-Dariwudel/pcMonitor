Guide de pcMonitor

pcMonitor 1.6.1 · Français · Josef Lehner

Prérequis et démarrage

pcMonitor 1.6.1 fonctionne sur Linux Mint avec Python 3.10 ou ultérieur, PyGObject et GTK 4.8 ou ultérieur. Installez python3, python3-gi et gir1.2-gtk-4.0. L’impression nécessite python3-cairo et python3-gi-cairo. L’édition compilée exige Python 3.12. Le programme lit les données ; il n’installe pas de pilotes et ne modifie pas le matériel.

Dans le dossier du programme, utilisez les commandes ci-dessous. --version affiche la version ; --check vérifie les ressources ; --scan produit un instantané JSON puis quitte. --admin demande via pkexec l’autorisation du lecteur ; l’interface reste dans la session normale. --help décrit les options. Le code de sortie est 0 en cas de réussite, 1 si la vérification ou l’autorisation demandée échoue. L’instantané peut contenir des numéros de série et des adresses réseau.

python3 -m monitor
python3 -m monitor --help
python3 -m monitor --version
python3 -m monitor --check
python3 -m monitor --scan
python3 -m monitor --admin

Utilisation

Sélectionnez une catégorie à gauche ou dans le menu Matériel. Les périphériques et leurs détails apparaissent à droite. La recherche filtre les résultats. Le filtre des ports vides ne change que l’affichage : aucun périphérique n’est déconnecté ou supprimé. Zéro est une valeur valide ; états inconnus et erreurs restent visibles. Le bouton de vue d’ensemble revient au résumé.

Dans Édition → Paramètres, choisissez une langue et un intervalle de 2, 3, 5 ou 10 secondes. L’option désactivée effectue une lecture initiale puis attend le bouton Actualiser. Une requête déjà lancée peut se terminer. Fichier → Quitter ferme proprement. Aide propose la documentation dans la langue choisie, la version, l’auteur et les composants utilisés.

Paramètres, langues et aide

Les réglages sont enregistrés dans config/settings.json ; les erreurs horodatées et leur contexte dans logs/. Le thème du système est respecté. Les catalogues languages/<code>.json sont des objets JSON UTF-8 à clés et valeurs textuelles, avec language.name. Ils sont redétectés à l’ouverture des paramètres. Une seule langue valide est sélectionnée automatiquement ; avec plusieurs langues, la sélection valide est conservée ou l’allemand est choisi. Les clés absentes utilisent l’anglais.

L’aide est recherchée indépendamment dans help/<code>.html et s’ouvre uniquement dans la langue choisie : aucune substitution par l’anglais si elle manque. Le serveur par défaut est https://github.com/Franz-Dariwudel/pcMonitor. Recherchez les langues disponibles puis installez la langue et son aide ensemble. L’installation est enregistrée immédiatement, même si le dialogue est ensuite annulé ; sélectionnez la langue et enregistrez pour modifier l’interface.

Vous pouvez aussi sélectionner un JSON local accompagné de son HTML, ou utiliser des dossiers voisins languages/ et help/. Chaque téléchargement est limité à 2 Mio, utilise HTTPS sans redirection et vérifie SHA256 et le contenu. Seul le HTML passif sans scripts, formulaires ni contenus externes intégrés est accepté. Les deux fichiers sont validés avant remplacement. Les erreurs d’écriture déclenchent un retour arrière ; une coupure électrique entre les deux remplacements n’est pas entièrement couverte. Conservez les fichiers .pack-backup si le retour arrière échoue. Une somme provenant du même serveur ne remplace pas une signature indépendante. Les mises à jour sont manuelles ; le programme fonctionne hors ligne.

Données et limites

Les catégories comprennent CPU, RAM et modules, carte mère, BIOS/UEFI, GPU, stockage, réseau, USB, écrans, PCIe, capteurs et numéros de série. lscpu et lspci complètent les données ; dmidecode et smartctl peuvent nécessiter des droits administrateur. Outils facultatifs : pciutils, dmidecode, smartmontools, pulseaudio-utils, ethtool, iw, nvme-cli et mokutil. N’installez que les outils indiqués par les diagnostics de votre machine.

La RAM disponible inclut les caches récupérables ; la VRAM désigne uniquement la mémoire dédiée. Le mode EDID préféré n’est pas la résolution actuelle. Le pourcentage du ventilateur n’est pas sa vitesse en tr/min. Les canaux de tension non étiquetés ne sont pas identifiés comme lignes 12/5/3,3 V. Les requêtes externes ont des délais limités ; certaines données statiques sont mises en cache jusqu’à cinq minutes. SMART ne lance pas de tests et évite de réveiller les disques en veille lorsque cette fonction est prise en charge. Une VM peut ne pas exposer les informations de l’hôte.

  • Port logique du concentrateur. Inclut les ports internes ; USB 2 et USB 3 peuvent désigner la même prise physique.
  • Le pilote indique l’état du connecteur et les modes pris en charge. Un écran connecté peut être désactivé.
  • Connecté signifie un signal de liaison, pas un accès Internet. Une interface désactivée administrativement peut ne pas indiquer la présence d’un câble.
  • La détection des prises nécessite la prise en charge du pilote et du serveur audio. « Inconnu » ne signifie pas vide.
  • Port SATA signalé par le noyau. Un disque est connecté même si son système de fichiers n’est pas monté.
  • Disque détecté. Cela ne renseigne pas sur d’autres emplacements physiques vides.
  • Emplacement signalé par le micrologiciel ou le noyau. Dans une VM, il peut être virtuel.
  • Nécessite un pilote Type-C compatible. Les périphériques USB peuvent aussi apparaître sous USB.
  • Périphérique Thunderbolt détecté ; l’autorisation est indiquée séparément.
  • Les ports série ne détectent souvent pas un appareil relié par un simple câble. Un adaptateur USB est détecté comme connecté.
  • Modules installés signalés par le micrologiciel. Des champs peuvent manquer ; fréquences et débits conservent les unités signalées.
  • Les champs du micrologiciel peuvent manquer ou contenir des valeurs fictives. Les numéros de série nécessitent souvent un accès administrateur.
  • La VRAM n’est affichée que si le pilote signale de la mémoire vidéo dédiée. La RAM partagée n’est pas présentée comme VRAM.
  • SMART est lu en mode administrateur avec smartmontools et mis en cache jusqu’à 60 secondes. Aucun autotest n’est lancé.

Impression et CSV

Au-dessus du panneau droit, choisissez Catégorie sélectionnée ou Toutes les données matérielles, puis Imprimer ou Enregistrer CSV. Un instantané pris au clic est utilisé, avec les périphériques masqués par les filtres et les remarques. Le CSV utilise UTF-8 avec BOM et le point-virgule ; les formules potentielles sont neutralisées en texte. Imprimer ouvre le dialogue système ; Annuler n’envoie aucun travail.

Erreurs et récupération

Ne confondez pas erreurs et ports vides. Les fonctions non touchées continuent si possible. Consultez le code, le fichier concerné et logs/. Faites une sauvegarde avant toute réparation.

HM404Un identifiant du micrologiciel ou du périphérique manque ou est fictif. Installer un logiciel ne crée pas les identifiants que le matériel ne fournit pas. La VM n’expose aucune sonde de température lisible. Les droits administrateur de l’invité ne créent pas de capteurs ; vérifiez d’abord l’hyperviseur.

Actualisez et vérifiez l’outil.
