دليل pcMonitor

pcMonitor 1.6.1 · العربية · Josef Lehner

المتطلبات والتشغيل

يعمل pcMonitor 1.6.1 على Linux Mint مع Python 3.10 أو أحدث وPyGObject وGTK 4.8 أو أحدث. ثبّت python3 وpython3-gi وgir1.2-gtk-4.0. تتطلب الطباعة python3-cairo وpython3-gi-cairo. النسخة المجمّعة تحتاج إلى Python 3.12. يقرأ البرنامج المعلومات فقط ولا يثبت برامج تشغيل أو يغيّر العتاد.

نفّذ الأوامر أدناه من مجلد البرنامج. يعرض --version الإصدار، ويفحص --check الموارد، ويُخرج --scan لقطة JSON ثم ينتهي. يطلب --admin صلاحية القارئ عبر pkexec؛ وتبقى الواجهة ضمن المستخدم العادي. يشرح --help الخيارات. رمز الخروج 0 للنجاح و1 لفشل الفحص أو التفويض المطلوب. قد تتضمن اللقطة أرقاماً تسلسلية وعناوين شبكة.

python3 -m monitor
python3 -m monitor --help
python3 -m monitor --version
python3 -m monitor --check
python3 -m monitor --scan
python3 -m monitor --admin

الاستخدام

اختر فئة من اليسار أو من قائمة الأجهزة. تظهر الأجهزة وتفاصيلها على اليمين. يرشّح البحث النتائج. يؤثر مرشح المنافذ الفارغة في العرض فقط، ولا يفصل الأجهزة أو يحذفها. الصفر قيمة صحيحة؛ وتبقى الحالات المجهولة والأخطاء ظاهرة. يعيد زر النظرة العامة الملخص.

في تحرير ← الإعدادات اختر اللغة وفاصل تحديث 2 أو 3 أو 5 أو 10 ثوانٍ. عند تعطيل التحديث تُجرى قراءة أولية ثم لا تُعاد القراءة إلا بزر تحديث. قد يكتمل استعلام بدأ بالفعل. يغلق ملف ← خروج البرنامج بصورة منظمة. توفر قائمة المساعدة الدليل باللغة المحددة والإصدار والمؤلف والمكونات المستخدمة.

الإعدادات واللغات والمساعدة

تُحفظ الإعدادات في config/settings.json والأخطاء المؤرخة مع السياق في logs/. يُحترم مظهر النظام. ملفات languages/<code>.json كائنات JSON بترميز UTF-8 بمفاتيح وقيم نصية، وتتضمن language.name. يُعاد اكتشافها عند فتح الإعدادات. تُختار اللغة الصحيحة الوحيدة تلقائياً؛ وعند تعددها يبقى الاختيار الصالح أو تُستخدم الألمانية. ترجع المفاتيح المفقودة إلى الإنجليزية.

يُبحث عن المساعدة بصورة مستقلة في help/<code>.html وتفتح باللغة المختارة فقط، دون التحول إلى الإنجليزية عند غيابها. الخادم الافتراضي هو https://github.com/Franz-Dariwudel/pcMonitor. ابحث عن اللغات المتاحة ثم ثبّت اللغة ومساعدتها معاً. يُحفظ التثبيت فوراً حتى لو ألغيت الحوار لاحقاً؛ لتغيير الواجهة اختر اللغة واحفظ.

يمكن اختيار JSON محلي مع HTML بجانبه أو استخدام مجلدين متجاورين languages/ وhelp/. الحد لكل ملف 2 MiB، ويُستخدم HTTPS دون تحويلات مع فحص SHA256 والمحتوى. يقبل HTML ساكن فقط دون سكربتات أو نماذج أو تضمينات خارجية. يُفحص الملفان قبل الاستبدال. يُتراجع عند أخطاء الكتابة؛ لا يمكن ضمان ذرية كاملة إذا انقطعت الكهرباء بين الاستبدالين. احتفظ بملفات .pack-backup عند فشل التراجع. مجموع التحقق من الخادم نفسه لا يحل محل توقيع مستقل. التحديثات يدوية والبرنامج يعمل دون الإنترنت.

البيانات والحدود

تشمل الفئات CPU وRAM ووحداتها واللوحة الأم وBIOS/UEFI وGPU والتخزين والشبكة وUSB والشاشات وPCIe والمستشعرات والأرقام التسلسلية. تكمل lscpu وlspci البيانات؛ وقد تحتاج dmidecode وsmartctl إلى صلاحية المسؤول. الأدوات الاختيارية: pciutils وdmidecode وsmartmontools وpulseaudio-utils وethtool وiw وnvme-cli وmokutil. ثبّت فقط ما تشير إليه تشخيصات جهازك.

تشمل RAM المتاحة الذاكرة المؤقتة القابلة للاسترداد؛ وVRAM تعني الذاكرة المخصصة فقط. وضع EDID المفضل ليس الدقة الحالية. نسبة المروحة ليست دورات في الدقيقة. لا تُخمن قنوات الجهد غير المعنونة على أنها خطوط 12/5/3.3 V. للاستعلامات الخارجية حدود زمنية؛ وتُخزن بعض البيانات الثابتة مؤقتاً حتى خمس دقائق. لا يبدأ SMART اختبارات ويتجنب إيقاظ الأقراص المنتظرة عند توفر الدعم. قد لا تعرض الآلة الافتراضية بيانات المضيف.

  • منفذ منطقي للموزّع، يشمل المنافذ الداخلية. قد يمثل USB 2 وUSB 3 المقبس الفعلي نفسه.
  • يبلغ برنامج التشغيل عن حالة الموصل والأوضاع المدعومة. قد تكون الشاشة المتصلة معطّلة.
  • متصل يعني وجود إشارة وصلة، وليس اتصالاً بالإنترنت. قد لا تبلغ الواجهة المعطّلة إدارياً عن وجود الكابل.
  • يتطلب اكتشاف المقابس دعم برنامج التشغيل وخادم الصوت. «مجهول» لا يعني فارغاً.
  • منفذ SATA تبلغ عنه النواة. يبقى القرص متصلاً حتى إن لم يُركّب نظام ملفاته.
  • قرص مكتشف. لا يعني ذلك معرفة الفتحات الفعلية الفارغة الأخرى.
  • فتحة تبلغ عنها البرمجيات الثابتة أو النواة. قد تكون افتراضية داخل آلة افتراضية.
  • يتطلب دعم برنامج تشغيل Type-C. قد تظهر أجهزة USB أيضاً ضمن USB.
  • اكتُشف جهاز Thunderbolt؛ يُعرض التصريح بشكل منفصل.
  • غالباً لا تكتشف المنافذ التسلسلية جهازاً عبر كابل بسيط. يُكتشف محوّل USB بوصفه متصلاً.
  • وحدات الذاكرة المثبتة وفق البرمجيات الثابتة. قد تغيب بعض الحقول؛ تبقى الترددات ومعدلات النقل بالوحدات المبلغ عنها.
  • قد تغيب حقول البرمجيات الثابتة أو تحتوي على قيم بديلة. غالباً تتطلب الأرقام التسلسلية صلاحية المسؤول.
  • تُعرض VRAM فقط عندما يبلغ برنامج التشغيل عن ذاكرة فيديو مخصصة. لا تُعرض RAM المشتركة باعتبارها VRAM.
  • تُقرأ SMART في وضع المسؤول باستخدام smartmontools وتُخزّن مؤقتاً حتى 60 ثانية. لا تبدأ اختبارات ذاتية.

الطباعة وCSV

اختر الفئة المحددة أو جميع بيانات العتاد أعلى اللوحة اليمنى ثم طباعة أو حفظ CSV. تُستخدم لقطة عند النقر تشمل الأجهزة المخفية بالمرشحات والملاحظات. يستخدم CSV ترميز UTF-8 مع BOM وفاصلة منقوطة؛ وتُحوّل الصيغ المحتملة إلى نص. تفتح الطباعة حوار النظام؛ والإلغاء لا يرسل مهمة طباعة.

الأخطاء والاستعادة

لا تخلط الأخطاء بالمنافذ الفارغة. تستمر الوظائف غير المتأثرة قدر الإمكان. راجع الرمز والملف المعني وlogs/. احتفظ بنسخة احتياطية قبل إصلاح البيانات.

خطأ في القراءةملاحظة
HM001Python 3 مفقود؛ لا يبدأ البرنامج. ثبّت python3.
HM002PyGObject أو GTK 4 مفقود؛ لا تفتح النافذة. ثبّت python3-gi وgir1.2-gtk-4.0.
HM003ملف برنامج مفقود أو غير قابل للقراءة. يتوقف البدء؛ استعد الحزمة الكاملة.
HM101لا يمكن الكتابة في logs/. تُستخدم مخرجات الخطأ للتسجيل. تحقق من الأذونات والمساحة الحرة.
HM102config/settings.json غير صالح أو غير قابل للقراءة. تُستخدم الإعدادات الافتراضية. انسخ الملف احتياطياً وأصلح JSON.
HM103ملف لغة مفقود أو غير صالح. يُتجاهل الملف؛ تحقق من UTF-8 وكائن JSON والقيم النصية ثم افتح الإعدادات مجدداً.
HM104HM104: تعذّر حفظ الإعدادات. تحقق من إذن الكتابة في config.
HM105HM105: المساعدة باللغة المحددة غير متاحة. استعد help/<language>.html وتحقق من المتصفح الافتراضي.
HM106أيقونة البرنامج أو المنفذ مفقودة. استعد الملف في resources/. لا تتغير بيانات الجهاز.
HM199خطأ غير متوقع قد يمنع العملية. احتفظ بالسجل ودوّن ما حدث ثم أعد تشغيل pcMonitor.
HM200تعذّر قراءة فئة. تستمر الفئات الأخرى ويظهر الخطأ. تحقق من برامج التشغيل والسجلات.
HM201لا توجد صلاحية قراءة لـ sysfs / procfs. شغّل وضع المسؤول لقراءة الحقل. تُعاد المحاولة عند التحديث اليدوي أو إعادة التشغيل.
HM202يوجد عتاد صوت، لكن pactl أو خادم الصوت غير متاح. شغّل البرنامج دون sudo ضمن جلسة المستخدم الرسومية.
HM203HM203: صلاحية المسؤول غير متاحة أو أُلغيت. يستمر الاكتشاف العادي. أعد تشغيل وضع المسؤول للمحاولة مجدداً.
HM204فشل استعلام عتاد إضافي. تبقى المعلومات الأساسية متاحة. تحقق من الأداة والأذونات والتوافق ثم حدّث.
HM301HM301: تعذّر حفظ CSV. تحقق من الوجهة وأذونات الكتابة.
HM302HM302: الطباعة غير متاحة. تحقق من الطابعة وحزمتي python3-cairo / python3-gi-cairo.
HM401الأداة {tool} مفقودة. يوفر Linux Mint هذه الحقول عبر الحزمة {package}. ثبّتها بالأمر: sudo apt install {package}
HM402لا يوجد برنامج تشغيل مرتبط بجهاز PCI ‏{device}. قد تكون وحدة مناسبة مفقودة أو غير محمّلة؛ وقد يكون الجهاز معطّلاً أو محجوزاً. لا يعني ذلك تلقائياً غياب حزمة. تحقق من معرّف الجهاز والدعم. لا يوجد برنامج تشغيل مرتبط بواجهة USB ‏{device}. بعض واجهات المصنّع أو فضاء المستخدم لا تحتاج إلى برنامج تشغيل للنواة. تحقق من وظيفة الواجهة قبل تثبيت أي شيء.
HM403تتطلب الحقول الإضافية وصولاً للقراءة بصلاحية المسؤول. شغّل pcMonitor في وضع المسؤول؛ تثبيت حزمة لا يمنح هذه الصلاحيات.
HM404معرّف البرمجيات الثابتة أو الجهاز مفقود أو بديل. تثبيت برامج لا ينشئ معرّفات لا يبلغ عنها الجهاز. لا تعرض الآلة الافتراضية مستشعرات حرارة قابلة للقراءة. صلاحيات مسؤول الضيف لا تنشئ مستشعرات؛ تحقق أولاً مما يعرضه برنامج المحاكاة الافتراضية.
HM405الأداة smartctl مثبتة، لكن بيانات صحة SMART غير متاحة. قد يكون السبب الاستعداد أو انتهاء المهلة أو دعم المتحكم أو فشل الوصول. تحقق من رسائل SMART؛ لم يثبت غياب حزمة. بيانات {tool} الإضافية غير متاحة. قد يكون السبب فشل الاستعلام أو انتهاء المهلة أو نقص الأذونات. حدّث البيانات وافحص الأداة.
HM501HM501: ملف اللغة غير صالح أو غير قابل للقراءة. اختر <language-code>.json بترميز UTF-8، بقيم نصية وlanguage.name (بحد أقصى 2 MiB). يجب أن يحتفظ الملف الإنجليزي بجميع المفاتيح الموجودة.
HM502HM502: خادم اللغات أو manifest.json غير متاح أو غير صالح. تحقق من عنوان HTTPS والاتصال وصيغة البيان. التحويلات غير مسموحة. تبقى اللغات المحلية متاحة.
HM503HM503: مجموع SHA256 غير مطابق. لم يُثبّت الملف. اطلب ملفاً مصححاً من المزوّد.
HM504HM504: تعذّر حفظ حزمة اللغة والمساعدة. تحقق من أذونات ومساحة languages/ وhelp/. يُتراجع عن الاستبدال؛ احتفظ بملفات .pack-backup إذا فشل التراجع.
HM505HM505: مساعدة HTML المطابقة مفقودة أو غير قابلة للقراءة أو تحتوي على محتوى غير مسموح. ضع <language-code>.html بجانب JSON أو في help/ المجاور. يُسمح فقط بـ HTML ساكن دون سكربتات أو تضمينات خارجية. لم يُثبّت شيء.
