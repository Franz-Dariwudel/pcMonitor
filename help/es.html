Guía de pcMonitor

pcMonitor 1.6.0 · Español · Josef Lehner

Requisitos y arranque

pcMonitor 1.6.0 funciona en Linux Mint con Python 3.10 o posterior, PyGObject y GTK 4.8 o posterior. Instale python3, python3-gi y gir1.2-gtk-4.0. Para imprimir se necesitan python3-cairo y python3-gi-cairo. La edición compilada requiere Python 3.12. El programa lee información; no instala controladores ni cambia el hardware.

En la carpeta del programa, ejecute los comandos siguientes. --version muestra la versión; --check comprueba los recursos; --scan devuelve una captura JSON y termina. --admin solicita autorización mediante pkexec para el lector; la interfaz sigue como usuario normal. --help describe las opciones. Un resultado correcto devuelve 0; un fallo de comprobación o de autorización solicitada devuelve 1. La captura puede contener números de serie y direcciones de red.

python3 -m monitor
python3 -m monitor --help
python3 -m monitor --version
python3 -m monitor --check
python3 -m monitor --scan
python3 -m monitor --admin

Uso

Seleccione una categoría a la izquierda o desde el menú Hardware. A la derecha aparecen sus dispositivos y detalles. La búsqueda filtra los resultados. El filtro de puertos vacíos solo cambia la presentación: no desconecta ni borra dispositivos. Los valores 0 son válidos; los estados desconocidos y los errores permanecen visibles. El botón de vista general vuelve al resumen.

En Editar → Configuración, elija el idioma y un intervalo de 2, 3, 5 o 10 segundos. La opción desactivada realiza una lectura inicial y después solo actualiza al pulsar Actualizar. Una consulta ya iniciada puede terminar. Archivo → Salir cierra ordenadamente. Ayuda ofrece la ayuda del idioma elegido, la versión, el autor y las bibliotecas utilizadas.

Configuración, idiomas y ayuda

Los ajustes se guardan en config/settings.json; los errores con fecha y contexto en logs/. Se conserva el tema del sistema. Los catálogos languages/<code>.json son objetos JSON UTF-8 con claves y valores de texto y un campo language.name. Los archivos se redetectan al abrir Configuración. Una sola lengua válida se selecciona automáticamente; con varias, se conserva la selección válida o se usa alemán. Las claves ausentes recurren al inglés.

La ayuda se busca independientemente en help/<code>.html y solo se abre en el idioma seleccionado: no cambia al inglés si falta. El servidor predeterminado es https://github.com/Franz-Dariwudel/pcMonitor. Pulse Buscar idiomas disponibles y luego Instalar / actualizar para recibir el idioma y su ayuda juntos. La instalación se guarda inmediatamente incluso si después cancela el diálogo; seleccione el idioma y guarde para cambiar la interfaz.

También puede seleccionar un JSON local con su HTML junto a él, o usar carpetas vecinas languages/ y help/. Cada descarga admite como máximo 2 MiB, usa HTTPS sin redirecciones y verifica SHA256 e integridad de contenido. Solo se acepta HTML pasivo sin scripts, formularios ni contenido externo incrustado. Primero se validan ambos archivos. Los fallos de escritura provocan una reversión; un corte eléctrico entre las dos sustituciones no puede cubrirse de forma totalmente atómica. Si falla la reversión, conserve .pack-backup. La suma del mismo servidor no sustituye a una firma independiente. Las actualizaciones son manuales y el programa sigue funcionando sin Internet.

Datos y límites

La lista incluye CPU, RAM y módulos, placa base, BIOS/UEFI, GPU, almacenamiento, red, USB, pantallas, PCIe, sensores y números de serie. lscpu y lspci amplían los datos; dmidecode y smartctl pueden necesitar permisos de administrador. Herramientas opcionales: pciutils, dmidecode, smartmontools, pulseaudio-utils, ethtool, iw, nvme-cli y mokutil. Instale únicamente lo que indiquen los diagnósticos para su equipo.

La RAM disponible incluye cachés recuperables; la VRAM solo indica memoria dedicada. El modo EDID preferido no es la resolución actual. El porcentaje del ventilador no equivale a RPM. Los canales de tensión sin etiqueta no se identifican como líneas de 12/5/3,3 V. Las consultas externas tienen límites de tiempo; algunos datos estáticos se guardan en caché hasta cinco minutos. SMART no inicia pruebas ni despierta deliberadamente unidades compatibles en espera. En una VM puede faltar información del equipo anfitrión.

  • Puerto lógico del concentrador. Incluye puertos internos; USB 2 y USB 3 pueden representar la misma toma física.
  • El controlador informa del estado del conector y los modos compatibles. Una pantalla conectada puede estar desactivada.
  • Conectado significa que hay señal de enlace, no acceso a Internet. Una interfaz desactivada administrativamente puede no indicar si hay cable.
  • La detección de conectores requiere compatibilidad del controlador y del servidor de audio. «Desconocido» no significa vacío.
  • Puerto SATA informado por el núcleo. Una unidad sigue conectada aunque su sistema de archivos no esté montado.
  • Unidad detectada. Esto no permite identificar otras ranuras físicas vacías.
  • Ranura informada por el firmware o el núcleo. En una máquina virtual puede ser una ranura virtual.
  • Requiere un controlador compatible con Type-C. Los dispositivos USB también pueden aparecer en USB.
  • Dispositivo Thunderbolt detectado; la autorización se muestra por separado.
  • Los puertos serie a menudo no detectan dispositivos conectados por un cable simple. Un adaptador USB se detecta como conectado.
  • Módulos instalados informados por el firmware. Pueden faltar campos; las frecuencias y tasas de transferencia conservan sus unidades originales.
  • Los campos del firmware pueden faltar o contener valores de relleno. Los números de serie suelen requerir acceso de administrador.
  • La VRAM solo se muestra si el controlador informa de memoria de vídeo dedicada. La RAM compartida no se presenta como VRAM.
  • SMART se lee con smartmontools en modo de administrador y se guarda en caché hasta 60 segundos. No se inician autopruebas.

Impresión y CSV

Seleccione Categoría seleccionada o Todos los datos del hardware sobre el panel derecho y pulse Imprimir o Guardar CSV. Se usa una captura del momento del clic, incluyendo dispositivos ocultos por filtros y avisos. El CSV usa UTF-8 con BOM y punto y coma; las fórmulas potenciales se neutralizan como texto. Imprimir abre el diálogo del sistema y Cancelar no envía trabajos.

Errores y recuperación

Los errores no deben confundirse con puertos vacíos. Las funciones no afectadas continúan cuando es posible. Consulte el código, el archivo implicado y logs/. Conserve copias de seguridad antes de reparar datos.
