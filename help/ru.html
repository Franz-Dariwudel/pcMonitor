Руководство pcMonitor

pcMonitor 1.6.1 · Русский · Josef Lehner

Требования и запуск

pcMonitor 1.6.1 работает в Linux Mint с Python 3.10 или новее, PyGObject и GTK 4.8 или новее. Установите python3, python3-gi и gir1.2-gtk-4.0. Для печати нужны python3-cairo и python3-gi-cairo. Скомпилированная версия требует Python 3.12. Программа только читает данные, не устанавливает драйверы и не изменяет оборудование.

В папке программы используйте команды ниже. --version показывает версию; --check проверяет ресурсы; --scan выводит снимок JSON и завершает работу. --admin запрашивает через pkexec права для модуля чтения; интерфейс остаётся в обычном сеансе. --help описывает параметры. Код выхода 0 означает успех, 1 — сбой проверки или запрошенной авторизации. Снимок может содержать серийные номера и сетевые адреса.

python3 -m monitor
python3 -m monitor --help
python3 -m monitor --version
python3 -m monitor --check
python3 -m monitor --scan
python3 -m monitor --admin

Работа с программой

Выберите категорию слева или в меню «Оборудование». Справа появятся устройства и подробности. Поиск фильтрует результаты. Фильтр пустых портов меняет только отображение: ничего не отключает и не удаляет. Ноль — допустимое значение; неизвестные состояния и ошибки остаются видимыми. Кнопка обзора возвращает к сводке.

В разделе Правка → Настройки выберите язык и интервал 2, 3, 5 или 10 секунд. При выключенном обновлении выполняется первое чтение, затем данные читаются только кнопкой «Обновить». Уже начатый запрос может завершиться. Файл → Выход корректно закрывает программу. В меню справки доступны руководство на выбранном языке, версия, автор и используемые компоненты.

Настройки, языки и справка

Настройки хранятся в config/settings.json, ошибки с временем и контекстом — в logs/. Используется тема системы. Каталоги languages/<code>.json — объекты JSON UTF-8 с текстовыми ключами и значениями, включая language.name. Они обнаруживаются заново при открытии настроек. Единственный корректный язык выбирается автоматически; при нескольких сохраняется корректный выбор, иначе выбирается немецкий. Недостающие ключи берутся из английского.

Справка независимо ищется в help/<code>.html и открывается только на выбранном языке, без замены на английский при отсутствии. Сервер по умолчанию: https://github.com/Franz-Dariwudel/pcMonitor. Найдите доступные языки и установите язык со справкой вместе. Установка сохраняется сразу, даже если затем отменить диалог; для смены интерфейса выберите язык и сохраните.

Можно выбрать локальный JSON с HTML рядом либо использовать соседние папки languages/ и help/. Размер каждого скачивания ограничен 2 МиБ; используются HTTPS без перенаправлений, проверка SHA256 и содержимого. Допускается только пассивный HTML без скриптов, форм и внешних вставок. Оба файла проверяются до замены. При ошибке записи выполняется откат; сбой питания между двумя заменами не может быть полностью атомарным. При ошибке отката сохраните .pack-backup. Сумма с того же сервера не заменяет независимую подпись. Обновления ручные; программа работает без Интернета.

Данные и ограничения

Категории включают CPU, ОЗУ и модули, материнскую плату, BIOS/UEFI, GPU, диски, сеть, USB, мониторы, PCIe, датчики и серийные номера. lscpu и lspci дополняют данные; dmidecode и smartctl могут требовать права администратора. Дополнительные средства: pciutils, dmidecode, smartmontools, pulseaudio-utils, ethtool, iw, nvme-cli и mokutil. Устанавливайте только то, что рекомендует диагностика для вашего оборудования.

Доступная ОЗУ включает освобождаемые кэши; VRAM означает только выделенную память. Предпочтительный режим EDID — не текущее разрешение. Процент вентилятора — не обороты в минуту. Каналы напряжения без подписи не угадываются как линии 12/5/3,3 В. Внешние запросы ограничены по времени; некоторые статические данные кэшируются до пяти минут. SMART не запускает тесты и старается не будить совместимые спящие диски. ВМ может не показывать сведения хоста.

  • Логический порт концентратора, включая внутренние порты. USB 2 и USB 3 могут обозначать один физический разъём.
  • Драйвер сообщает состояние разъёма и поддерживаемые режимы. Подключённый монитор может быть выключен программно.
  • «Подключено» означает наличие сигнала связи, а не доступ в Интернет. Программно отключённый интерфейс может не сообщать о кабеле.
  • Определение подключения к аудиоразъёму требует поддержки драйвера и звукового сервера. «Неизвестно» не означает «пусто».
  • Порт SATA, сообщённый ядром. Накопитель подключён, даже если его файловая система не смонтирована.
  • Обнаруженный накопитель. Это не даёт сведений о других пустых физических слотах.
  • Слот, сообщённый прошивкой или ядром. В виртуальной машине он может быть виртуальным.
  • Нужна поддержка драйвера Type-C. USB-устройства также могут отображаться в разделе USB.
  • Обнаружено устройство Thunderbolt; разрешение на доступ показано отдельно.
  • Последовательные порты часто не обнаруживают устройство на обычном кабеле. USB-адаптер определяется как подключённый.
  • Установленные модули памяти по данным прошивки. Поля могут отсутствовать; частоты и скорости передачи сохраняют исходные единицы.
  • Поля прошивки могут отсутствовать или содержать заглушки. Для серийных номеров часто нужны права администратора.
  • VRAM показывается только при сообщении драйвером о выделенной видеопамяти. Общая ОЗУ не отображается как VRAM.
  • SMART читается через smartmontools в режиме администратора и кэшируется до 60 секунд. Самотестирование не запускается.

Печать и CSV

Над правой панелью выберите «Выбранная категория» или «Все данные оборудования», затем «Печать» или «Сохранить CSV». Используется снимок на момент нажатия, включая скрытые фильтром устройства и замечания. CSV использует UTF-8 с BOM и точку с запятой; возможные формулы обезвреживаются как текст. Печать открывает системный диалог; отмена не отправляет задание.

Ошибки и восстановление

Не путайте ошибки с пустыми портами. Незатронутые функции по возможности продолжают работать. Проверьте код, соответствующий файл и logs/. Перед исправлением данных сделайте резервную копию.
